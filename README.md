# Перенос избранной музыки

Проект переносит понравившиеся треки из Яндекс Музыки в медиатеку Apple Music.
Сначала он выгружает список треков из Яндекса, затем ищет их в Apple Music и
добавляет найденные. Результаты поиска сохраняются в CSV-отчёте.

## Что нужно

- Python 3
- Токен Яндекс Музыки
- Apple Music и настроенный инструмент из папки `applemusic-agent-skill`

Установите библиотеку для экспорта:

```bash
python3 -m pip install yandex-music
```

Перед первым переносом настройте Apple Music CLI по инструкции в
[`applemusic-agent-skill/README.md`](applemusic-agent-skill/README.md).

## Запуск

Запускайте команды из папки проекта.

1. Выгрузите понравившиеся треки. Скрипт запросит токен Яндекс Музыки и создаст
   `yandex_liked.csv`.

   ```bash
   python3 export_yandex.py
   ```

2. Запустите поиск и перенос в Apple Music.

   ```bash
   python3 transfer.py
   ```

Скрипт переноса сохраняет прогресс в `transfer_state.json`, а итог поиска — в
`transfer_report.csv`. При повторном запуске уже обработанные треки пропускаются.
